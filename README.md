# JASON INVEST — version corrigée (prototype)

Cette version corrige les appels API manquants du ZIP original et les noms de fichiers JavaScript incohérents.

## Important
Les comptes, dépôts, retraits et investissements de cette version sont stockés dans `localStorage` du navigateur. C'est donc un **prototype de démonstration** : les données ne sont pas une base de données serveur et aucun paiement réel n'est traité.

Pour une version de production, il faudra connecter une vraie base de données et une authentification serveur.
